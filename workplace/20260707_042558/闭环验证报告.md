## 5. 架构变更

```
变更前:
  ChatApp
  ├── handleUserMessageAsync → doLlmCall → LLM ❌ (agent职责混入)
  ├── processToolCalls → 工具调用 ❌
  └── agent广播

变更后:
  ChatApp (纯聊天室)
  ├── 接收消息 → 记录history
  ├── @agent路由 → 指定agent
  ├── 无@广播 → 所有agent
  └── push_output → WebSocket

  AgentChatParticipant (聊天角色)
  ├── onUserMessage → LLM处理
  ├── system_prompt → YAML配置
  └── responseCallback → 回复
```
